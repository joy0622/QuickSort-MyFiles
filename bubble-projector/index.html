사진 파일을 이 화면에 끌어다 놓거나, 아래 버튼을 눌러 주세요.

실물화상기나 웹캠도 카메라 목록에서 고를 수 있어요.

F 크게 보기 · Ctrl+V 붙여넣기 · 말풍선은 끌어서 옮기고, 두 번 누르면 글을 고쳐요

⚙️ 설정

한 줄에 한 문장씩 적어 주세요. 사진을 올릴 때마다 이 중에서 골라 붙여요.
문장에 “…”이 있으면 💭 생각 풍선, “!!”이나 “최고·대박”이 있으면 💥 외침 풍선으로 붙어요.

O사진 파일 올리기 (끌어다 놓기, Ctrl+V 붙여넣기도 돼요) C카메라 열기 → Space로 찍기 F크게 보기 (빔프로젝터 전체 화면) ← →이전 / 다음 사진 (Space도 다음) R말풍선 다시 붙이기 B말풍선 하나 더 (빈 곳을 두 번 누르면 그곳을 가리키는 말풍선) H말풍선 숨기기 / 짠! 보이기 P자동 넘김 켜기 / 끄기 S말풍선 붙은 그림 저장 (PNG) E고른 말풍선 글 고치기 (두 번 눌러도 돼요) D고른 말풍선 다른 말로 T고른 말풍선 모양 바꾸기 (말풍선 → 생각 → 외침 → 글상자) + −글자 크게 / 작게 (고른 말풍선이 없으면 전체) Delete고른 말풍선 지우기
