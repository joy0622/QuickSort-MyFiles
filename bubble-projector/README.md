# 💬 말풍선 프로젝터

그림을 사진으로 찍거나 파일로 올리면 **말풍선이 저절로 붙고**, 빔프로젝터에 **크게 띄울 수 있는** HTML 한 파일입니다.
설치할 것이 없고 서버도 필요 없습니다. 사진은 컴퓨터 밖으로 나가지 않습니다.

## 여는 법

1. `index.html` 파일을 내려받습니다.
2. 파일을 더블클릭해서 **크롬**이나 **엣지**로 엽니다.
3. 처음 카메라를 쓸 때 "카메라 사용 허용"을 눌러 줍니다.

## 이렇게 써요

| 하고 싶은 것 | 방법 |
| --- | --- |
| 사진 올리기 | 📁 버튼, 화면에 끌어다 놓기, `Ctrl+V` 붙여넣기 (여러 장 한꺼번에 가능) |
| 카메라로 찍기 | 📷 버튼 → `Space` (실물화상기·웹캠은 카메라 목록에서 고르기) |
| 빔프로젝터로 크게 | 🖥️ 버튼 또는 `F` — 마우스를 가만히 두면 메뉴가 숨어요 |
| 다음 / 이전 사진 | `→` `←` 또는 `Space`, ⏯️ 자동 넘김 |
| 말풍선 옮기기 | 끌어서 옮기기, 빨간 점을 끌면 꼬리 방향이 바뀌어요 |
| 글 고치기 | 말풍선을 두 번 누르기 (`Shift+Enter`로 줄바꿈) |
| 말풍선 더 붙이기 | 빈 곳을 두 번 누르면 그곳을 가리키는 말풍선이 생겨요 |
| 새로 붙이기 | 🔄 버튼 또는 `R` |
| 짠! 하고 보여 주기 | `H`로 말풍선을 숨겼다가 다시 `H` |
| 그림으로 저장 | 💾 버튼 또는 `S` (PNG, 다운로드 폴더) |

⚙️ 설정에서 말풍선 문구(재미있는 말 / 칭찬하는 말 / 발표·소개 / 직접 쓰기), 사진 한 장에 붙일 말풍선 수, 글자 크기, 바탕색을 바꿀 수 있습니다.
문구에 “…”이 있으면 💭 생각 풍선, “!!”이나 “최고·대박”이 있으면 💥 외침 풍선으로 붙습니다.

## 말풍선 자리는 어떻게 정하나요?

인공지능이 아니라 그림의 **빈 곳과 그린 선**을 보고 정합니다.
도화지의 빈 곳에 말풍선을 놓고, 꼬리는 그림 위쪽(대개 머리)을 가리킵니다.
얼굴 찾기를 지원하는 브라우저에서는 사진 속 얼굴을 피해서 붙입니다.
마음에 들지 않으면 `R`을 누르거나 끌어서 옮기면 됩니다.
