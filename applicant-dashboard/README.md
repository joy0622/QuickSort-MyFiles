# 신청자 관리 대시보드

구글 폼으로 받은 신청자를 한 화면에서 관리하는 HTML 대시보드입니다.
**출석 여부 · 문자 발송 여부 · 참가 상태 · 특이사항 메모**를 기록할 수 있고,
구글 폼으로 새 응답이 들어오면 자동으로 화면에 반영됩니다.

파일은 두 개뿐입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 대시보드 화면 전체 (외부 라이브러리 없음, 파일 하나로 동작) |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 연동용 스크립트 (실시간 연동을 쓸 때만 필요) |

---

## 1. 먼저 화면부터 열어보기

`index.html` 을 더블클릭해서 브라우저로 열면 **샘플 데이터**로 모든 기능을 바로 만져볼 수 있습니다.
연동 설정 없이도 출석 토글, 메모, 검색, 일괄 처리, CSV 내보내기가 전부 동작합니다.

마음에 들면 아래에서 실제 시트를 연결하세요.

---

## 2. 연동 방식 고르기

오른쪽 위 **⚙ 설정** 에서 세 가지 중 하나를 고릅니다.

| | ① 실시간 연동 (권장) | ② 시트 CSV | ③ 샘플 데이터 |
|---|---|---|---|
| 신청자 목록 자동 갱신 | ✅ | ✅ | — |
| 출석·문자·메모 저장 위치 | **구글 시트** | 내 브라우저 | 내 브라우저 |
| 여러 명이 나눠서 관리 | ✅ 가능 | ❌ 각자 따로 보임 | ❌ |
| 컴퓨터를 바꿔도 기록 유지 | ✅ | ❌ | ❌ |
| 준비 시간 | 5분 | 1분 | 0분 |

> 실제 행사 운영에는 **① 실시간 연동**을 쓰세요.
> ②는 "일단 명단만 보고 싶다"일 때, 혹은 혼자 노트북 한 대로만 쓸 때 적당합니다.

---

## 3. ① 실시간 연동 설정 (5분)

### 3-1. 스크립트 붙여넣기

1. 폼 응답이 쌓이는 **구글 스프레드시트**를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. 편집기에 있던 `function myFunction() {}` 를 **전부 지우고**,
   이 저장소의 `apps-script/Code.gs` 내용을 **전체 복사해서 붙여넣습니다.**
4. 💾 저장 (Ctrl/⌘ + S).

### 3-2. 웹 앱으로 배포

1. 오른쪽 위 파란 **배포 → 새 배포** 버튼.
2. 톱니바퀴(유형 선택) → **웹 앱** 선택.
3. 아래처럼 설정합니다.
   - **설명**: 아무거나 (예: 신청자 대시보드 v1)
   - **다음 사용자 인증 정보로 실행**: `나`
   - **액세스 권한이 있는 사용자**: **`모든 사용자`**  ← 이게 핵심입니다
4. **배포** 를 누르면 권한 승인 창이 뜹니다.
   - "이 앱은 확인되지 않았습니다" 경고가 나오면
     **고급 → (프로젝트 이름)(으)로 이동 → 허용** 순서로 진행하세요.
     내가 만든 내 스크립트라서 나오는 정상적인 경고입니다.
5. 배포가 끝나면 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfycb..../exec` 형태입니다.

### 3-3. 대시보드에 붙여넣기

1. `index.html` 을 열고 **⚙ 설정** → **① 실시간 연동** 선택.
2. 복사한 URL 을 **Apps Script 웹 앱 URL** 칸에 붙여넣습니다.
3. **연결 테스트** 를 눌러 "연결 성공 — 신청자 N건" 이 뜨는지 확인합니다.
4. **저장하고 불러오기**.

끝났습니다. 이제 출석·문자·메모를 누를 때마다 구글 시트에 바로 저장되고,
다른 사람이 같은 URL 로 대시보드를 열어도 같은 기록이 보입니다.

### 시트에는 무엇이 생기나요?

- 응답 시트 맨 오른쪽에 **`_관리ID`** 열이 하나 생깁니다.
  행이 삭제되거나 정렬돼도 메모가 엉뚱한 사람에게 붙지 않도록 하는 고유 번호입니다. 지우지 마세요.
- **`_관리데이터`** 라는 숨김 시트가 생기고, 여기에 출석/문자/상태/메모가 저장됩니다.
  (스프레드시트 메뉴 **신청자 관리 → 관리 시트 보이기** 로 직접 확인할 수 있습니다.)
- 폼 응답 내용 자체는 **읽기만 하고 절대 수정하지 않습니다.**

### 폼이나 시트가 바뀌면 자동으로 따라오나요?

대시보드는 새로고침할 때마다 시트의 **머리글과 내용을 처음부터 다시 읽습니다.**
그래서 대부분은 손댈 것이 없습니다.

| 무슨 일이 생기면 | 대시보드는 |
|---|---|
| 폼으로 새 신청이 들어옴 | 자동 반영. `NEW` 배지가 붙습니다 |
| 신청자가 자기 응답을 수정함 | 자동 반영. 적어둔 메모·출석 기록은 그대로 따라갑니다 |
| 폼에 문항을 **추가**함 | 상세 패널에는 바로 보입니다. 표에도 띄우려면 **⚙ 열 설정**에서 한 번 체크 |
| 폼에서 문항을 **삭제**함 | 시트에는 기존 답변이 열째로 남습니다. 표에서 빼려면 **⚙ 열 설정**에서 체크 해제 |
| 문항 제목을 바꿈 | 시트 머리글이 바뀌면 대시보드 열 이름도 따라 바뀝니다 |
| 시트에서 행을 지움 | 명단에서 사라집니다 |
| `Code.gs` 를 직접 고침 | 이때만 **재배포**가 필요합니다 (아래 7번 표 참고) |

> 문항을 추가해도 이름·연락처 인식이나 기존 메모 연결은 깨지지 않습니다.
> `_관리ID` 열은 위치가 아니라 **이름으로** 찾기 때문에, 열이 뒤로 밀려도 상관없습니다.

### "자동 반영"이 정확히 어떤 뜻인가요?

- 대시보드는 **열려 있는 동안** 기본 30초마다 시트를 다시 읽습니다. 즉 최대 30초 지연이 있습니다.
- 다른 창을 보다가 대시보드 탭으로 **돌아오면 즉시** 한 번 갱신합니다.
- 급하면 **↻ 새로고침** 버튼을 누르면 됩니다.
- 브라우저를 닫아둔 동안에는 아무 일도 일어나지 않습니다. 서버가 아니라 페이지이기 때문입니다.
  다시 열면 그 시점의 최신 명단을 불러옵니다.
- 갱신 주기는 **⚙ 설정 → 자동 새로고침 간격**에서 바꾸거나 `0` 으로 끌 수 있습니다.

## 4. ② 시트 CSV 방식 (1분)

1. 스프레드시트에서 **파일 → 공유 → 웹에 게시**.
2. 게시할 시트로 **폼 응답 시트**를 고르고, 형식을 **쉼표로 구분된 값(.csv)** 으로 선택 후 **게시**.
3. 나오는 주소를 대시보드 **⚙ 설정 → ② 시트 CSV** 칸에 붙여넣고 저장.

신청자 목록은 자동으로 갱신되지만, 출석·문자·메모는 **그 브라우저에만** 저장됩니다.
다른 PC 에서 열면 기록이 보이지 않으니 주의하세요.

## 5. 화면 사용법

**통계 카드** — 클릭하면 그 조건으로 바로 필터링됩니다. (전체 / 새 신청 / 출석 / 미출석 / 문자 발송 / 미발송 / 취소)

**새 신청 배지** — 마지막으로 확인한 뒤 새로 들어온 신청자에게 `NEW` 배지가 붙습니다.
카드의 **확인** 버튼을 누르면 초기화됩니다.

**중복 배지** — 같은 연락처로 두 번 이상 접수되면 이름 옆에 `중복` 이 표시됩니다.

**출석 / 문자** — 셀의 알약 버튼을 클릭할 때마다 켜짐/꺼짐이 전환되고 즉시 저장됩니다.

**메모** — 표에서 바로 입력하거나, 행을 클릭해 상세 패널의 큰 입력창에 씁니다. 자동 저장됩니다.

**일괄 처리** — 왼쪽 체크박스로 여러 명을 고르면 상단에 막대가 나타납니다.
출석 일괄 처리, 문자 발송 표시, 상태 변경, 그리고 **📋 연락처 복사**(선택한 사람들의 번호를 쉼표로 이어서 복사 → 문자 발송 사이트에 붙여넣기)를 쓸 수 있습니다.

**🖨 인쇄** — 출석부 형태로 인쇄됩니다. 툴바와 통계는 빠지고 **서명란**이 추가됩니다.

**⤓ CSV 내보내기** — 지금 화면에 보이는(필터가 적용된) 명단을 출석·문자·상태·메모까지 포함해 내려받습니다. 엑셀에서 한글이 깨지지 않습니다.

**단축키** — `/` 검색, `R` 새로고침, `Esc` 닫기.

## 6. 여러 명이 함께 쓰려면

`index.html` 은 서버가 필요 없는 파일 하나이므로, 아래 중 편한 방법을 쓰면 됩니다.

- **가장 간단**: 파일을 카톡·메일로 보내주고 각자 열게 한 뒤, 설정에서 같은 웹 앱 URL 을 입력.
- **GitHub Pages**: 이 저장소의 Settings → Pages 에서 배포하면
  `https://<계정>.github.io/QuickSort-MyFiles/applicant-dashboard/` 주소로 접속할 수 있습니다.

> ⚠️ **개인정보 주의**
> 대시보드를 공개 주소(GitHub Pages 등)에 올리고 Apps Script 를 "모든 사용자" 로 배포하면,
> **URL 을 아는 사람은 누구나 신청자 명단을 볼 수 있습니다.**
> 공개 주소에 올릴 계획이라면 반드시 `Code.gs` 상단의
> ```js
> API_TOKEN: '아무도-모를-긴-문자열'
> ```
> 을 채우고 **재배포**한 뒤, 대시보드 설정의 *접근 토큰* 칸에 같은 값을 넣으세요.
> 토큰을 모르면 데이터를 읽을 수 없게 됩니다.
> 담당자끼리만 쓸 거라면 파일을 각자 PC 에 두고 여는 편이 가장 안전합니다.

## 7. 잘 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| "연결 실패" 가 계속 뜸 | 배포 시 **액세스 권한이 있는 사용자**가 `모든 사용자` 인지 확인하세요. `나만` 으로 두면 브라우저에서 읽지 못합니다. |
| "응답을 해석할 수 없습니다" | 위와 같은 원인입니다. 로그인 페이지 HTML 이 대신 돌아온 경우입니다. |
| `Code.gs` 를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. 새로 저장만 해서는 바뀌지 않습니다. |
| 출석·메모가 저장되지 않음 | 화면 오른쪽 위 표시등이 빨간색이면 저장 실패입니다. 실패한 변경은 대기열에 남아 다음 저장 때 다시 시도합니다. |
| 이름·연락처 열을 못 찾음 | 문항 제목에 "이름/성함", "연락처/전화번호" 같은 단어가 들어가면 자동으로 인식합니다. 인식이 안 되어도 **⚙ 열 설정**에서 직접 고르면 됩니다. |
| 파일을 더블클릭해서 열었더니 연동이 안 됨 | 일부 브라우저는 `file://` 에서 외부 요청을 막습니다. GitHub Pages 에 올리거나, 폴더에서 `python3 -m http.server` 로 열어보세요. |

## 8. 기술 메모

- 외부 라이브러리·빌드 도구 없음. `index.html` 하나로 동작합니다.
- 저장은 변경 후 0.7초 디바운스 → `saveMany` 로 묶어서 전송합니다. 창을 닫을 때는 `sendBeacon` 으로 남은 변경을 보냅니다.
- POST 는 `Content-Type: text/plain` 으로 보내 CORS 프리플라이트를 피합니다 (Apps Script 제약).
- 자동 새로고침 기본 30초. 설정에서 바꾸거나 `0` 으로 끌 수 있습니다. 탭을 다시 열면 즉시 갱신합니다.
- 서버에서 목록을 다시 받아도, 아직 전송되지 않은 내 변경분은 덮어쓰지 않습니다.
