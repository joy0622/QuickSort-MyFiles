데이터 연동 설정

스프레드시트 → 확장 프로그램 → Apps Script 에 Code.gs 를 붙여넣고 배포 → 새 배포 → 웹 앱(액세스: 모든 사용자)으로 배포한 뒤 나오는 /exec 주소입니다. 자세한 절차는 저장소의 README.md 를 보세요.
시트 → 파일 → 공유 → 웹에 게시 → 형식 CSV 로 게시한 주소를 넣으세요. 신청자 목록은 자동으로 갱신되지만, 출석·문자·메모는 이 브라우저에만 저장됩니다.
0 을 넣으면 자동 새로고침을 끕니다. 구글 폼 응답이 들어오면 이 주기로 화면에 반영됩니다.
